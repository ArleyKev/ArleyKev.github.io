System Monitor (Sysmon) is Windows system service that is responsible for monitoring and logging system activity to the Windows event log. It gives us the detailed information about process creations and network connections.  
Wazuh is an open source security platform that provides threat detection, prevention & response. It has three main components – 
1.	Wazuh Agent - It collects data from monitored endpoints.
2.	Wazuh server – It examines and processes data received from agents to identify threats & indicators of compromise (IOCs).
3.	Elastic Stack – It indexes and saves Wazuh server alerts.
